# Изолированное окружение

Замки ловят обычную ошибку — забывчивость модели. Границу ущерба задаёт
окружение. Здесь лежит шаблон этой границы; почему именно так — в
[docs/THREAT-MODEL.md](../../docs/THREAT-MODEL.md).

## Запуск

```bash
UID=$(id -u) GID=$(id -g) podman compose -f compose.yml run --rm agent
```

С docker — та же команда через `docker compose`. Скопируйте каталог к себе
в проект и правьте под свой стек: добавьте в `Containerfile` то, что нужно
для сборки и тестов.

## Что даёт

- процесс идёт от непривилегированного пользователя;
- сокет контейнерного движка не проброшен — изнутри нельзя поднять
  привилегированный контейнер и добраться до хоста;
- ключи (`~/.ssh`, `~/.gnupg`, облачные учётные данные) не монтируются;
- на запись доступен только каталог проекта;
- настройки Claude Code примонтированы только на чтение: правка хуков изнутри
  отключила бы проверки;
- ограничены память и число процессов;
- сняты все capabilities, запрещено повышение привилегий.

## Чего не даёт

**Сеть открыта.** Агенту нужны пакетные репозитории и документация, а разумный
список разрешённых адресов зависит от стека. Для недоверенной работы
раскомментируйте `network_mode: none` в `compose.yml` и поставьте зависимости
заранее, на этапе сборки образа.

**Это не защита от человека с доступом к машине.** Модель угроз — ошибка
агента, а не злоумышленник за клавиатурой.
