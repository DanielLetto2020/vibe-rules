# JS/TS: поведение во время выполнения

Правила уровня языка, независимо от фреймворка. Про систему типов — отдельный
модуль `std-js-typescript`: он подключается там, где есть TypeScript, и не
мешает проектам на чистом JavaScript.

- Каждый `await` рассчитан на отказ: либо `try/catch`, либо осознанное
  всплытие выше. Необработанное отклонение промиса роняет процесс в Node.
- `Promise.all` падает целиком при первом отказе. Если частичный результат
  допустим — `Promise.allSettled`.
- Никаких «плавающих» промисов: результат асинхронного вызова либо ожидается,
  либо явно помечается как намеренно проигнорированный.
- Сравнение строгое (`===`). Значение по умолчанию — через `??`, а не `||`:
  `0 || 'по умолчанию'` даёт строку, а `'' || 'x'` подменяет пустую строку —
  почти никогда не то, что задумано.
- Мутация аргументов и общих объектов запрещена: возвращай новое значение.
  Функция, меняющая переданный объект, ломается при повторном использовании.
- Числа с плавающей точкой не годятся для денег: `0.1 + 0.2 !== 0.3`.
  Минимальные единицы целыми числами либо десятичный тип.
- Даты — с явной зоной. `new Date('2026-07-26')` разбирается как UTC,
  а `new Date('2026/07/26')` — как локальное время.
- `console.log` в рабочем коде — только через логгер с уровнями.
- Обработчики событий, таймеры и подписки снимаются при уничтожении
  компонента: незакрытая подписка — утечка, которая проявится не сразу.
