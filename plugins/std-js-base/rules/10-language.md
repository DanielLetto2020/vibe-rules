# JS/TS: язык

Правила уровня языка, независимо от фреймворка — Vue, Nuxt, Node, скрипт.

- `any` запрещён. Если тип неизвестен — `unknown` с явной проверкой:
  `unknown` заставляет сузить тип, `any` отключает проверки молча.
- Приведение через `as` — признак того, что тип получен неправильно. Особенно
  `as unknown as T`: это отключение проверок в две ступени.
- Данные извне (ответ API, `localStorage`, параметры URL) валидируются схемой.
  Тип в TypeScript — обещание компилятору, а не проверка во время работы.
- Каждый `await` рассчитан на отказ: либо `try/catch`, либо осознанное
  всплытие выше. Необработанное отклонение промиса роняет процесс в Node.
- `Promise.all` падает целиком при первом отказе. Если частичный результат
  допустим — `Promise.allSettled`.
- Сравнение строгое (`===`). Проверка на существование — `??` и `?.`,
  а не `||`: `0 || 'по умолчанию'` даст строку, что почти никогда не нужно.
- Мутация аргументов и общих объектов запрещена: возвращай новое значение.
- Никаких «плавающих» промисов: результат асинхронного вызова либо ожидается,
  либо явно помечается как намеренно проигнорированный.
- `console.log` в рабочем коде — только через логгер с уровнями.
