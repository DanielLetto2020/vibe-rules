# Laravel: HTTP-слой

- Валидация — только в FormRequest. В контроллере нет `$request->validate()`.
- Контроллер не содержит бизнес-логики: принял, делегировал в Action, вернул
  Resource. Ориентир — метод до 15 строк (проверяется PHPStan/Pint).
- Ответ наружу — только через API Resource. Модель напрямую не отдаём:
  добавленное поле в БД иначе немедленно утекает в публичный контракт.
- Авторизация — Policy или Gate, не `if ($user->role === 'admin')`.
- Роут ссылается на invokable-класс либо на `[Controller::class, 'method']`,
  замыкания в роутах не используем — их нельзя закэшировать.
- Изменение существующего эндпоинта — изменение контракта: нужен человек,
  зелёные тесты этого не заменяют.

Подробности и примеры: `docs/http-layer.md` (прочитай при сомнениях).
