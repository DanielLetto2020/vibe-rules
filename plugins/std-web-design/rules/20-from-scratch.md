# Дизайн: когда рисуем с нуля

У языковой модели есть оформление по умолчанию, и оно узнаётся с первого
взгляда: фиолетово-синий градиент, крупный заголовок по центру, три карточки
со скруглением и тенью, эмодзи вместо иконок, шрифт Inter. Это не стиль,
а отсутствие решения — среднее по обучающим данным.

Признак, по которому это отличается от работы: **ни один выбор нельзя
объяснить.** Почему этот цвет, этот отступ, этот шрифт — ответа нет.

- Направление формулируется до вёрстки, одной фразой: для кого, какое
  ощущение, чем отличается от соседей. «Строгий инструмент для ежедневной
  работы» и «витрина, которая должна нравиться» — разная вёрстка.
- Сначала задаются токены — палитра, шкала размеров, шкала отступов,
  радиусы, — и только потом верстается первый экран. Обратный порядок даёт
  набор случайных значений, который потом никто не приведёт в систему.
- Палитра ограничена: один акцент, нейтральный ряд, цвета состояний.
  Три ярких цвета в равных долях — верный признак, что палитру не выбирали.
- Градиент — приём для отдельного случая, а не фон страницы. Фиолетово-синий
  градиент на всю ширину — самая узнаваемая примета оформления по умолчанию.
- Шрифт выбирается осознанно; системный набор — честный вариант по умолчанию,
  а вот Inter «потому что везде» — это отсутствие выбора.
- Типографика строится шкалой: три-четыре размера с ясной разницей. Набор
  из десяти близких размеров читается как небрежность.
- Отступы — из одной шкалы, кратные общей единице. Одинаковые отступы вокруг
  разных по важности блоков стирают структуру страницы.
- Иерархия делается размером, весом и расстоянием, а не рамками и тенями
  вокруг всего. Тень на каждом блоке означает, что не выделен ни один.
- Эмодзи не заменяют иконки в интерфейсе: они по-разному выглядят в разных
  системах и выдают черновик.
- Плотность соответствует задаче: рабочий инструмент требует компактности,
  посадочная страница — воздуха. Одинаковые большие отступы везде — признак
  шаблона.
- Первый экран отвечает на вопрос «что это и что здесь делать», а не украшает.
- Хотя бы одно решение должно быть намеренно нетиповым — сетка, работа
  с цветом, подача заголовков. Без этого получится аккуратно и безлико.
