# Playwright: E2E

E2E-тесты — верхняя ступень надзора: они единственные проверяют систему так,
как её видит пользователь. Их беда — нестабильность: тест, падающий через раз,
через месяц отключают, и надзор исчезает вместе с ним.

- Селекторы — по роли и тексту (`getByRole`, `getByLabel`, `getByText`).
  CSS-классы и id меняются при вёрстке, `data-testid` — только там, где
  доступной роли действительно нет.
- Ожидания — только автоматические (`expect(...).toBeVisible()`).
  `waitForTimeout` запрещён: он либо тормозит прогон, либо не спасает
  на медленной машине.
- Каждый тест сам создаёт свои данные и не зависит от порядка выполнения
  и от результатов соседних тестов.
- Вход в систему — через сохранённое состояние (`storageState`), а не
  прокликиванием формы логина в каждом тесте.
- Внешние сервисы (платежи, почта, карты) — через `page.route`. Реальные
  обращения делают тест зависимым от чужой доступности.
- Проверяем результат, видимый пользователю, а не внутреннее состояние:
  «на странице появился номер заказа», а не «в localStorage записан id».
- Флакающий тест либо чинится, либо удаляется в тот же день. `test.skip`
  без задачи и срока — это молчаливая потеря покрытия.
- Артефакты при падении (trace, скриншот, видео) включены в конфиге: без них
  разбор падения в CI невозможен.
