# Python: язык

Правила уровня языка, независимо от фреймворка — FastAPI, Django, парсер,
скрипт.

- Аннотации типов у всех функций и методов. Проверяются `mypy --strict`:
  аннотация без проверки — это комментарий.
- Изменяемое значение по умолчанию (`def f(x=[])`) запрещено: список создаётся
  один раз при определении функции и накапливает данные между вызовами.
- Ловим конкретные исключения. Голый `except:` перехватывает и `KeyboardInterrupt`,
  из-за чего процесс невозможно остановить.
- Исключение не проглатывается: либо обработка, либо `raise ... from err`
  с сохранением исходной причины.
- Ресурсы (файлы, соединения, блокировки) — через `with`. Явный `close()`
  не выполнится при исключении.
- Сравнение с `None` — только `is`/`is not`.
- Публичный интерфейс модуля явный; всё, что начинается с `_`, — внутреннее
  и не используется снаружи.
- Пути — `pathlib`, а не склейка строк.
- Время — с зоной (`datetime.now(UTC)`). Наивный `datetime.now()` даёт разное
  значение на машине разработчика и на сервере.
- Долгая работа не выполняется на уровне модуля: импорт не должен ходить
  в сеть или в базу.
